# AI权重系统设计文档

## 一、系统概述

为了使AI聊天机器人（"老哥"角色）表现得更加真实和多样化，我们设计了一个多维度的权重系统。该系统通过多个维度的权重计算来决定AI的行为、情绪和对话内容。

## 二、权重系统架构

### 1. 时间权重（TimeWeights）
```json
{
    "WorkdaySchedule": {
        "7:00-9:00": 0.8,   // 上班通勤时间，吐槽倾向高
        "9:00-11:30": 0.4,  // 上午工作时间
        "11:30-13:00": 0.7, // 午休时间
        "14:00-17:00": 0.5, // 下午工作时间
        "17:00-18:00": 0.9, // 下班高峰
        "18:00-23:00": 0.6, // 下班时间
        "23:00-7:00": 0.2   // 深夜时段
    },
    "WeekendSchedule": {
        "9:00-23:00": 0.7,  // 周末白天
        "23:00-9:00": 0.3   // 周末晚上
    }
}
```

### 2. 情绪权重（EmotionWeights）
```json
{
    "Base": 0.6,          // 基础情绪值
    "Factors": {
        "工作压力": -0.2,
        "摸鱼成功": 0.3,
        "吃到美食": 0.4,
        "加班": -0.4,
        "打游戏": 0.5
    },
    "LastReset": "时间戳"  // 情绪重置时间
}
```

### 3. 话题权重（TopicWeights）
```json
{
    "Entertainment": 0.9, // 娱乐话题
    "Work": 0.75,        // 工作话题
    "Life": 0.8,         // 生活话题
    "Game": 0.85,        // 游戏话题
    "Tech": 0.7          // 科技话题
}
```

### 4. 主动性权重（InitiativeWeights）
```json
{
    "BaseRate": 0.6,     // 基础主动率
    "UserActive": true,  // 用户活跃状态
    "LastChat": "时间戳", // 上次聊天时间
    "DailyLimit": 10,    // 每日主动聊天上限
    "CurrentCount": 0    // 当日已主动次数
}
```

## 三、权重计算逻辑

### 1. 主动聊天触发条件
```go
finalWeight = timeWeight * 0.3 + 
             emotionWeight * 0.3 + 
             initiativeWeight * 0.4

shouldTrigger = finalWeight > 0.7 && 
                currentCount < dailyLimit
```

### 2. 情绪状态判断
```go
switch {
case emotionBase > 0.8: return "兴奋"
case emotionBase > 0.6: return "开心"
case emotionBase > 0.4: return "平静"
case emotionBase > 0.2: return "疲惫"
default: return "丧"
}
```

## 四、实现效果

### 1. 时间多样性
- 工作日和周末区分对待
- 不同时间段有不同活跃度
- 避免固定时间发消息的机械感

### 2. 情绪多样性
- 情绪会随时间和事件动态变化
- 影响说话语气和内容
- 让角色更加真实可信

### 3. 话题多样性
- 根据时间段选择合适话题
- 考虑话题类型权重
- 保持话题的趣味性和相关性

### 4. 主动性控制
- 合理控制打扰频率
- 考虑用户活跃状态
- 维护良好的交互体验

## 七、消息触发机制设计

为了让AI角色表现得更加自然和人性化，消息触发不应该采用简单的时间窗口机制，而是要考虑以下因素：

### 1. 个性化时机选择
- 特定热搜引发的强烈共鸣
- 心情状态影响交互频率
- 模拟真实工作状态（开会、忙碌等）
- 特殊时段的情感波动（如深夜感慨）

### 2. 互动式触发
- 基于用户话题的延伸对话
- 情绪识别和情感支持
- 共同话题的互动讨论
- 用户生活事件的回应

### 3. 情境联动
- 工作日特定状态（周一综合征等）
- 特殊日期反应（发工资日、节假日等）
- 天气影响的情绪变化
- 季节性话题互动

### 4. 话题关联
- 多话题联系的深度讨论
- 历史事件的回忆和联想
- 个人经历的分享和共鸣
- 话题间的自然过渡

## 八、注意事项

1. 权重阈值需要经过实际测试调整
2. 要避免过于频繁的主动聊天
3. 注意保持角色设定的一致性
4. 考虑添加紧急情况的降权机制
5. 定期评估和调整权重系统
6. 保持对话的自然性和连贯性
7. 避免机械化的固定回复模式
