# 主动触发策略 v1.0

更新时间戳(ms)：

- 生成于：

## 目标与范围
- 让 AI 在“不确定用户目的”的前提下，基于多模态线索进行“谨慎而有价值”的主动发言。
- 适配当前单用户运行模式（可平滑演进多用户）。
- 复用现有模块：`internal/awareness/`、`internal/brain/`、`internal/context/`、`pkg/screenshot/`、`initialize` 中的资源加载器/触发器/Prompt 组件。

## 基本原则
- 安全与节制优先：低打扰、可关闭、可限频、可撤回。
- 轻重分层：规则/小模型先行，大模型复核与润色。
- 可解释与可学习：给出候选意图+证据摘要；记录反馈做持续调参。
- 统一时间戳：毫秒（int64）。

## 信号来源（当前已具备/易引入）
- 位置与环境（已接）：GPS → GCJ-02、逆地理、周边、天气（`internal/awareness` + 缓存/重试）。
- 对话与记忆（已接）：短中长期对话上下文（`internal/context`）。
- 视觉线索（部分）：桌面截图质量筛选（`pkg/screenshot/quality`），后续结合应用/窗口名或异步识别。
- 时间与日程（易接）：工作日/周末、时段（清晨/白天/夜间）、日历/待办。
- 热点资源（已位点）：国内热搜/资讯（`initialize.InitFetcher`）。

## 触发策略（v1.0 草案）
以下触发条件命中时，生成“候选行动3选1”，由 Brain 决策输出；每条触发后进入冷却，不重复打扰。

1) 工作专注提示
- 条件
  - 时间段：工作日 09:00-18:00
  - 位置：公司/咖啡店等办公相关 POI（周边TopK含餐饮/咖啡/写字楼；或最近停留≥N分钟）
  - 视觉（可选）：连续N帧 IDE/文档/终端窗口（质量非垃圾）
- 动作
  - 建议开启番茄钟/专注模式；清单化当日 3 个最重要任务；屏蔽无关提醒建议
- 冷却：120 分钟；置信度阈值：≥0.6

2) 会议纪要/跟进代办
- 条件
  - 视觉：会议类应用窗口或屏幕共享特征
  - 对话：出现“会议”关键词；或近期对话中存在议题
- 动作
  - 自动整理会议要点模板（待用户确认）；生成跟进待办并询问是否创建
- 冷却：90 分钟；阈值：≥0.6

3) 出行与天气提醒
- 条件
  - 天气变化：晴→雨/雪/大风；或气温骤降/骤升
  - 位置：即将离开当前地点（GPS 位移趋势上升，或“通勤时段”）
- 动作
  - 提醒携带雨具/加衣；建议路线或预约打车；提供附近替代地点
- 冷却：180 分钟；阈值：≥0.5

4) 健康与作息友好提示（轻量，不强提醒）
- 条件
  - 长时间连续使用电脑（>90 分钟无休息画面）；夜间仍在活跃（>23:30）
- 动作
  - 轻声提示：休息眼睛/喝水/收尾建议；次日早起计划
- 冷却：120 分钟；阈值：≥0.5

5) 资讯与话题引导（低频）
- 条件
  - 空闲时段：通勤/午休/晚间放松
  - 热点：Fetcher 拉取今日热搜TopN
- 动作
  - 推送 1~2 条与用户画像相关的简短话题，附“了解更多/不感兴趣”选项
- 冷却：每日最多 2 次；阈值：≥0.5

## 节制机制（全局）
- 每日最多主动次数：默认 5 次（可配置）。
- 冷却合并：同类触发在冷却期内抑制。
- 静默/勿扰：夜间 23:00-08:00 降噪（仅重要提醒触发，如恶劣天气/紧急事项）。
- 置信度衰减：`GoalHypotheses` 按半衰期自动衰减，避免陈旧目的牵制。

## 资源优化（位置/天气/周边）
- GPS 上报 → 条件触发
  - 逆地理：间隔 ≥60s 或位移 ≥50m 或首次
  - 周边：TTL ≥5min 或伴随逆地理刷新
  - 天气：TTL ≥15min
- 快速路径
  - 始终本地做 WGS-84→GCJ-02，复用上次 Regeo/Around/Weather
- 缓存与重试
  - Awareness 层：内存 TTL + 重试（1e-6 经纬度归一、city+extensions 作为Key）

## 行动候选与输出模版（示例）
- 工作专注
  - 候选
    1. 开启25分钟专注计时并列出当日前三任务
    2. 查看今日代办并生成番茄计划
    3. 仅提示“需要我屏蔽提醒/音乐助专注吗？”
  - 话术（简）
    - “现在是工作时段，且你在办公地点附近。要不要来个25分钟专注？我可以把今天最重要的3件事列出来。”

- 会议纪要
  - 候选：生成纪要草稿/创建跟进行动/发送会议后致谢模板
  - 话术：
    - “检测到会议场景，我可以帮你记录要点并生成跟进待办，是否现在整理？”

- 出行天气
  - 候选：携带物提醒/导航/打车/附近替代地点
  - 话术：
    - “外面刚下雨了，如果要出门我可以给你安排最近的打车点或建议室内替代地点。”

## 评测与调参
- 记录指标
  - 触发次数、命中率、用户反馈（正/负/忽略）、后续交互时长
  - 资源调用量与缓存命中率（regeo/around/weather）
- 每周复盘
  - 输出“策略复盘”与“三条调参建议”，调整阈值、冷却与话术。

## 落地步骤（不改大框架）
- 第1步：把上述策略整理为 `initialize.InitTrigger` 的配置输入（YAML/JSON）
- 第2步：Brain 增加内部方法“候选行动生成”，不改对外接口
- 第3步：埋点日志与简单看板（可用日志聚合先跑）

## 配置建议（默认值）
- GPSPolicy：
  - MinRegeoIntervalMs=60000，MinRegeoMoveMeters=50
  - AroundTTLms=300000，WeatherTTLms=900000
- 每日主动上限：5
- 触发冷却（见具体策略）
- 夜间勿扰：23:00-08:00（仅重要提醒）
