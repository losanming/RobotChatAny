## 🎯 实施策略

### 核心原则
1. **纯软件优先**: 所有功能不依赖硬件设备
2. **文本交互为主**: 暂不实现语音输入输出
3. **数据驱动智能**: 利用 RAG 和规则引擎提供价值
4. **快速迭代**: 先实现 MVP，再逐步优化
5. **用户可见**: 优先开发用户能直接感知的功能

### 技术选型补充
- **TTS 方案**: MiniMax speech-01-turbo（免费额度充足）
- **ASR 方案**: 浏览器 Web Speech API（前端临时方案）或百度语音识别免费层
- **本地 LLM**: Ollama + Qwen2.5（可选，降低 API 成本）

### 4. MiniMax TTS 集成

**SDK 封装**:
```go
// pkg/tts/minimax/client.go
package minimax

import (
    "bytes"
    "encoding/json"
    "fmt"
    "io"
    "net/http"
)

type Client struct {
    apiKey string
    baseURL string
}

type TTSRequest struct {
    Model       string      `json:"model"`        // speech-01-turbo
    Text        string      `json:"text"`
    VoiceID     string      `json:"voice_id"`     // 音色ID
    Speed       float64     `json:"speed,omitempty"`
    Volume      float64     `json:"volume,omitempty"`
    Pitch       int         `json:"pitch,omitempty"`
    Emotion     string      `json:"emotion,omitempty"` // happy, sad, angry, neutral
}

type TTSResponse struct {
    AudioURL    string      `json:"audio_url"`
    Duration    float64     `json:"duration"`
}

func (c *Client) Synthesize(req TTSRequest) ([]byte, error) {
    body, _ := json.Marshal(req)
    httpReq, _ := http.NewRequest("POST", c.baseURL+"/v1/tts", bytes.NewBuffer(body))
    httpReq.Header.Set("Authorization", "Bearer "+c.apiKey)
    httpReq.Header.Set("Content-Type", "application/json")

    resp, err := http.DefaultClient.Do(httpReq)
    if err != nil {
        return nil, err
    }
    defer resp.Body.Close()

    return io.ReadAll(resp.Body)
}
```

**配置示例**:
```yaml
# config.yaml
tts:
  provider: minimax
  api_key: "YOUR_MINIMAX_API_KEY"
  base_url: "https://api.minimax.chat/v1"
  default_voice: "female-shaonv"
  default_emotion: "neutral"
  default_speed: 1.0
```

**应对**:
- 聚焦核心场景（健康管理、任务管理）
- 每个阶段只完成最关键的 3-5 个功能
- 避免过度工程化

### 风险 3: 用户参与度低
**应对**:
- 快速推出 MVP 获取反馈
- 设计激励机制（连续打卡、成就系统）
- 提供真正有用的主动建议
