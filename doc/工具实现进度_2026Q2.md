## 🔧 技术实现要点

### 统一的数据库访问模式

所有工具采用一致的架构：

```go
type XxxTool struct {
    db *xorm.Engine
}

func (t *XxxTool) SetDB(db *xorm.Engine) {
    t.db = db
}

func (t *XxxTool) getDB() *xorm.Engine {
    if t.db == nil {
        return public.DB
    }
    return t.db
}
```

### 数据持久化流程

1. **接收参数** → 解析 JSON
2. **验证参数** → 检查必填字段和格式
3. **构建模型** → 转换为 model.Xxx 结构
4. **数据库操作** → Insert/Update/Delete/Find
5. **返回结果** → 序列化为 JSON

### 辅助函数统一化

在 `internal/tools/personal/common.go` 中提供：
- `getStringParam()` - 获取字符串参数
- `getIntParam()` - 获取整数参数
- `getInt64Param()` - 获取64位整数参数
- `getStringArrayParam()` - 获取字符串数组参数
- `contains()` - 字符串包含检查
- `toJSON()` - JSON序列化

### 错误处理规范

```go
if err != nil {
    return "", fmt.Errorf("操作失败: %w", err)
}
```
